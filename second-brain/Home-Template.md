2. Add a source and date to claims that may become outdated.
3. Never store passwords, API keys, private keys, recovery phrases, or broker credentials in notes synced to GitHub.
4. Treat AI-generated output as a draft until checked.
5. Trading notes are research, not a command to execute a trade.
